# IBAM - Système de Gestion des Réclamations

Ce projet est une plateforme de gestion des réclamations de notes pour l'IBAM, construite avec Laravel (Backend) et React (Frontend).

## Fonctionnalités

- Authentification sécurisée (Étudiant, Enseignant, Scolarité, Admin)
- Dépôt de réclamations de notes
- Suivi en temps réel du statut
- Gestion administrative centralisée

## Installation

### Backend (Laravel)
1. `composer install`
2. `php artisan migrate --seed`
3. `php artisan serve`

### Frontend (React)
1. `npm install`
2. `npm run dev`
